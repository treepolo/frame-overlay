# 幀數標註工具 (frame-overlay)

在影片每一幀上燒入幀號，並附上固定浮水印 `IG@treepolooo`。浮水印與幀號共用同一個底框，位置會依幀號所在位置自動切換，讓畫面難以裁切。

## 需求

- Windows
- Python 3（建議 3.11 以上）
- Pillow：`pip install pillow`
- ffmpeg 與 ffprobe，並加入系統 PATH

## 啟動

雙擊 `start_frame_overlay.bat`，會以無主控台的 `pythonw` 開啟視窗。

也可以在終端機執行：

```bash
python frame_overlay.py
```

## 使用方式

1. **選擇輸入影片**：輸出路徑會自動設為同一資料夾，檔名為 `原檔名_標註.mp4`。
2. **調整樣式**：字型、幀數字大小、字色、描邊、底框（顏色、不透明度、內距）。
3. **調整位置**：在右側預覽拖曳底框移動；拖曳右下角藍色方塊或使用滾輪縮放字級；「水平垂直置中」可一鍵置中。
4. **預覽播放**：可播放、暫停、停止，也可以用進度條跳轉。
5. **開始輸出**：進度條會顯示已處理幀數與百分比。

## 規則

- **幀號從 0 開始**。
- **浮水印**：內容固定為 `IG@treepolooo`，字型、字色、描邊都與幀數字相同。字級為幀數字的 32/68，間距為幀數字的 8/68，會隨幀數字等比例變化。
- **上下位置**：幀號中心在畫面上半部，浮水印放在下方；在下半部，放在上方。
- **字級下限**：短邊 1080 時最小為 74，其他解析度依短邊等比例換算。輸入小於下限的值會自動改成下限。
- **底框邊界**：底框會被限制在畫面內，不會超出右側或下方。

## 輸出編碼

- 會先檢查 NVIDIA 的 `h264_nvenc` 是否可用，可用就用 GPU 編碼。
- 不可用時自動改用 `libx264`（CPU）。
- 幀號與浮水印由 Pillow 在多個 CPU 核心上並行繪製，再依順序寫入。

## 預覽副本

載入影片時，程式會產生一份 720p、每幀皆為關鍵幀的預覽副本，存放在 `_proxy/`，播放與跳轉都從它讀取，讓操作更順暢。輸出仍使用原始影片。同一支影片（路徑、大小、修改時間都相同）只會產生一次。

## 設定檔

設定會自動儲存在 `settings.json`，下次開啟時載入。這個檔案只屬於本機，已列入 `.gitignore`。

## 疑難排解

- **GPU 編碼無法使用**：NVENC 需要較新的 NVIDIA 驅動。使用 ffmpeg 9.x 時，需要驅動 610.00 以上；驅動較舊時會自動改用 CPU 編碼，結果正確，只是較慢。
- **找不到 ffmpeg**：確認 `ffmpeg -version` 能在終端機執行，且已加入 PATH。
- **字型清單是空的**：程式會讀取 `C:\Windows\Fonts` 下的 `.ttf` 與 `.otf` 檔案。
